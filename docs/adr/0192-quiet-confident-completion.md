# ADR-0192: Quiet Confident Completion Through Existing Work

Date: 2026-10-02. Status: Accepted for the authorized unpublished local slice.
Architecture accepted; scoped independent native review qualified acceptance. No deployment is authorized.

Amends ADR-0187's human outcome and activity projection. Preserves ADR-0190's one frozen
resolution, ADR-0191's exact resource retirement, ADR-0186's background attention,
ADR-0106's caller-owned CLI continuity, and ADR-0132's complete MCP rendering.

## Context

The owner defines delight as quiet confident success. The approved test is "save a draft while
I keep working", judged by completion, unnecessary calls, human interruptions, confirmation,
and cleanup. The independent installed review found mistaken cancellation/disconnection wording,
inconsistent history scope, generic waits, alarm styling for preserved tabs, repeated selector
advice, and stale-looking empty CLI continuity.

The existing executor, semantic discovery, form transaction, flow, waits, workspace custody,
and completion already perform the successful draft journey. A second task pipeline would add
ownership and failure paths without making this journey simpler.

## Decision

1. Discover bounded current controls once. Fill, click Save once, wait for an explicit fresh
   application condition, and read through ordinary tools in one flow. The short action `expect`
   stays short. Neither dispatch nor a pre-existing success marker proves application persistence.
   Owned tests compare page observations with an independent server save counter and values.
2. Work keeps the actual closed cancellation cause. A local delay cancelled before the next
   dispatch has no effect and does not imply disconnection. Partial prefixes and uncertain
   mutations keep their existing evidence and never invite replay. Lost observation receipts are
   classified by the exact command at the existing evidence seam: no requested mutation means
   no mutation effect, with an honest unavailable observation. Earlier mutation evidence remains.
   Page code may continue after resource retirement.
3. One wait condition and settlement path uses the original deadline, exact tab, validated
   receipt, and latest readiness. Settlement errors preserve their cause. Language authors a
   closed content-free live purpose, phase, and budget through the existing operation update.
   The budget is measured on phase entry; it is not a second deadline or a countdown service.
   The same resolved owned tab supplies Show tab. No page condition value enters audit.
4. Use existing inspection and its precise generation-bound handles. An ambiguous semantic
   query remains a safe refusal, with one useful inspection route instead of exhausted refinement
   advice. No additional ambiguity result contract or handle registration is added. The engine
   never chooses by position.
5. A no-effect tab-preservation interlock or tab-close policy refusal uses a calm human outcome
   and no repeated native guardrail popup. Both gates remain enforced. Unknown and partial
   effects take precedence. The exact manual Show tab route stays available.
6. The UI cache retains the authority's 500 history groups separately from its 200 displayed
   entries. Event and snapshot updates maintain the same cached operations and history. Clear
   view hides completed retained groups without deleting audit; Show retained activity restores
   the bounded display without reviving completed work or dropping live work. Counts name their
   scope. Connected clients, retained tabs, and dormant empty continuity are distinct projections.
   No workspace lifetime rule changes.

Architecture review narrowed this candidate before acceptance. Cache counts/bounds and completed-
only history resync are verified. General live hero ordering equivalence is not claimed: an
inherited two-operation completion/resync mismatch remains for focused investigation. An inherited
document inspection context gap also needs investigation: tree state can be stored internally
while callers receive metadata/counts. Adding another result list is not its substitute.

CLI and MCP remain thin. No new relay mechanism, lifecycle system, journal, background retry,
policy exception, or page-success inference is added. The exact tool column and the complete
guardian About card, artwork, palette, and motion remain. Adjacent About facts state retained
history and admitted workspace scope.

## Amendment: native rejection and current composed purpose (2026-10-02)

Native review of `66213c61` confirmed once-only draft persistence, calm protection, scoped history
and the guardian card, but rejected complete quiet-success UX acceptance. Observe cancellation
did not promptly dispose its original handler. ADR-0191's observation amendment repairs that
same correlated cleanup owner. Correct outcome wording alone does not satisfy next-read recovery.

A composed save also had the actual wait purpose in its existing live operation, while the hero
preferred the earlier child receipt's "Completed 2 of 4 steps." The renderer now leads with current
live activity for unsettled work. The existing Language-authored composition summary remains
secondary progress. It does not become a new counter or progress authority. The existing child
audit receipt boundary clears bounded wait progress; the next phase supplies its own purpose.
Settled work uses its canonical outcome as before. No page condition text is retained.

The [correction report](../testing/quiet-success-correction-2026-10-02.md) records first immediate
reads, genuine observer disposal, live/rebuilt rendering, final gates and cleanup.

## Acceptance record (2026-10-02)

The architect accepted frozen authority `1fdad4ae` and manifest `afab4675`. The independent
[corrected native review](../testing/quiet-success-correction-native-review-2026-10-02.md) gave
qualified acceptance to the scoped draft journey. The first immediate same-tab reads succeeded
without polling, retry or reset in 141/146 ms from Cancel, while animation and earlier draft effects
remained. The 12-second composed save showed current purpose, configured budget and child counts
live and in a recreated native window; completion removed the old wait purpose. CLI/MCP each
persisted once without replay. All 43 frozen files matched before and after independent review.

This accepts the bounded local implementation. Physical keyboard activation, actual operator
attention, full OS foreground transfer, inherited concurrent hero ordering and inspection-context
projection remain outside acceptance. No release, installation, deployment or publication is approved.
