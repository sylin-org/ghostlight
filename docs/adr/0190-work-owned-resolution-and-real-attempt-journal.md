# ADR-0190: Work-Owned Resolution and a Real Attempt Journal

Date: 2026-10-01. Status: Accepted for the authorized unpublished local improvement trial.

Amends ADR-0103's outcome projection, ADR-0187's retained human presentation and ADR-0169's
single pre-handler journal save. Preserves ADR-0156's child receipts, ADR-0159's independent
history storage, ADR-0163's historical readers and ADR-0185/0186's explicit controls.

## Context

The executor independently assembled a caller result and audit projection, then repaired them
in completion. A follow-up observation could replace the action account. Composition read
causes back from audit. Historical presentation inferred what new work meant from stored fields.
An acknowledged keyboard prefix could disappear when a later stroke was refused.

Two isolated journal counterexamples exposed a separate mechanism defect. The first awaited save
ran before the fresh command entered the journal map. Overlapping command and acknowledgment
saves could also finish in the wrong order. A full journal refused a fresh handler but reported
uncertain effects. These are reproduced mechanism failures, not evidence of live automatic replay.

The owner approved a bounded cleanup after reading the architecture investigation: one account
of action truth, real attempt ordering and removal of competing interpretations. This decision
does not authorize a runtime update or establish installed acceptance.

## Decision

1. Work owns mutable invocation evidence and consumes it once into an immutable resolution.
   Admission, preparation, requested effects, declared verification and compensation are distinct
   responsibilities within the existing executor. They are not new middleware or services.
   Preserve the lease, snapshot, budget, capability checks, final live admission and exact custody.
2. A physical reply establishes attempt evidence. It does not alone confirm requested effects.
   Confirm effects only after the receipt matches the request identity and the admitted document
   scope validates. Every command has an explicit effect classification. A malformed dispatched
   mutation remains uncertain; an unsent action following failed preparation remains effect-free.
   Confirm each keyboard landing and apply its governed workspace generation before sending the
   next stroke. A denied landing or stale target stops the remainder while retaining the prefix.
3. Verification adds Met, NotMet or Unavailable evidence to the action; absent verification remains
   explicit. A failed check cannot erase a confirmed change. Closing a denied tab is cleanup, not
   proof that visiting the page caused no effects. Known visits remain unsafe to repeat.
4. Freeze the resolution before completion reactions, diagnostics and audit. Work evidence and
   frozen resolution are non-Clone ownership values; no result buffer can be drained and reopened.
   Composition reads the child's frozen status, effects, cause, readiness and repeat safety directly.
   Preserve its existing accumulator, original snapshot and lease, and ordinary child receipts.
5. Language derives caller, content-minimized retained metadata and human presentation from that
   frozen resolution in one projection. Transient script results, page text, values, caller strings
   and raw browser errors are separate client payload. No client fact authors retained language.
   CLI plain output renders the service-authored text, including the same safe next steps as MCP.
6. Retain additive optional resolution metadata and its authored human presentation. New records
   use it directly. Missing or unsupported optional data uses a named legacy reader without editing
   bytes or hiding valid neighbors. Keep new composition causes in optional metadata; map those
   outside the predecessor's strict nested vocabulary to its existing safe cause for older readers.
7. Register a fresh dispatched ID before the sole pre-handler awaited journal save. Capture each
   queued snapshot and serialize activation, attempt, completion and acknowledgment saves. Preserve
   duplicate joining, memory receipts, old phases, bounded IDs and epoch recovery. A fresh full-journal
   refusal has a distinct code and known no-effect result. Restored uncertain work remains uncertain.
   No new ordinary-success roundtrip, sleep, automatic replay or receipt queue is added.

## Retirements and boundaries

Retire the old Terminal result/audit assembly, postcondition field overwrites, final-effect audit
repair, audit-based child causes, duplicate dispatch conversion, reusable CompletionGate,
unused target helper, duplicate recovery markup and summary-only CLI rendering. Do not retain
an inactive alternative builder. Preparation-only history facts still use their closed language.

Exact tool names remain primary in the activity list. The existing hero, history, safe guidance,
expandable machine facts, Pause during reconnect, Show tab and no-replay Resume/Start behavior
remain. The complete Sylin guardian About card, art, shell, shared palette and styles are untouched.
History search targeting remains deferred. No hold, task-intent inference, acknowledgement ritual,
panel system, notification engine, deployment, version bump, publishing or outreach is added.

## Validation

Source acceptance must separately count actual synthetic handlers and effects before judging
wording. Cover preparation loss versus mutation reply loss, script false/throw/lost reply,
verified and unavailable conditions, acknowledged prefixes followed by refusal or malformed
receipts, invalid document scope, workspace update failure, mixed Continue and held cleanup.
Cover safe retained privacy, current and predecessor readers, unsupported nested optional data,
valid neighboring records, original JSONL bytes, CLI/MCP text parity and journal crash/overlap.

All repository gates precede a local commit. Independent structural review and whole-journey
human/agent comprehension acceptance precede any parent-authorized runtime change. A source
test or component snapshot is not installed UX acceptance.
