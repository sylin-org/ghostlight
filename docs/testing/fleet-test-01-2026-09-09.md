## Defects and corrections

### Targeted typing could erase an unfocused draft

The full installed live journey failed at `browser_type_text(clear_first:true)`.
A controlled reproduction confirmed that another desktop application's focus caused the
old implementation to clear the rich editor, then refuse tab-wide input with
`document scope changed before access`. Independent observation found an empty draft,
unchanged Chrome document identity, and `status:unknown`. Foreground controls succeeded.
The original failure is retained; it was not retried as a safe operation.

The extension now routes targeted typing to the exact admitted document. It selects the
replacement range without clearing it, then performs one native browser editing transaction.
It neither activates the browser nor guesses frame identity by URL. Focused typing retains
its separate desktop-focus rule and checks admission before clearing. This follows ADR-0138's
owning-frame rule and retains H6 document admission. Validation failures after content dispatch
still use the existing conservative unknown-effect boundary.

Installed checks passed: foreground/background/foreground reproduction; 24 replacement/append
checks across ordinary inputs, textareas, rich and shadow editors in foreground, another-app,
and inactive-tab states; and three inactive-tab frame checks including duplicate-URL siblings
and a cross-origin frame. Replacement produced exactly one trusted input event, no synthetic
input, no submission, and no focus theft. Original and corrected evidence remain separate.

### Declared output rejected actual receipts

OpenCode rejected actual Ghostlight results because the closed output schema omitted the
always-serialized `history_storage` field. This happened even with valid URL-only arguments.
The orchestrator catalog now declares the required closed `saved` / `unconfirmed` field.
The connectors remain unchanged. A canonical-receipt regression covers all 23 tool schemas and
both storage states. Independent JSON Schema validation reproduces rejection of actual Copilot
receipts by the old schema and acceptance by the corrected schema, while still refusing unknown
or missing storage. The corrected authority was deployed through the documented dev-loop. OpenCode then passed
URL-only navigate/read using the same declared receipt schema.

### Debian lifecycle inspection pipelines could misreport success or failure

With `pipefail`, early-exit `grep -q` caused a valid `dpkg-deb` producer to fail with
SIGPIPE. The same pattern could hide a forbidden RPATH match. Inspection pipelines now
drain their producers. Original and traced failures remain local. The corrected script
passed actual package lifecycle checks on Debian 12 and Ubuntu 24.04, plus `bash -n`.
