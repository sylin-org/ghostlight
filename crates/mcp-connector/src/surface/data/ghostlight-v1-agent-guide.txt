Ghostlight gives you short, task-shaped browser tools in the user's visible, authenticated browser. Start with the user's job; you do not need a status check, manual focus, or generic wait before ordinary work. Omit tab when the current controlled tab is unambiguous. Navigation and actions wait briefly for normal page settlement. Use browser_inspect_page for controls, browser_read_page for prose, and browser_take_screenshot for appearance. Use browser_run_sequence only when every child argument is already known. Ghostlight never guesses a destructive tab, ambiguous target, credential field, or uncertain effect. Read status, effect, repeat, and suggested_next_steps before deciding what to do next; never repeat an outcome_unknown call automatically.
