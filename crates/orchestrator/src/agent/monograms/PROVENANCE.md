# Integration artwork provenance

Date: 2026-08-15

All SVGs in this directory are neutral Ghostlight-owned fallback marks created for the integration
workbench. They use product initials in simple colored tiles. They do not copy vendor logos or
claim vendor endorsement. The adjacent product name remains the primary accessible identity.

These fallbacks are packaged so integration recognition works offline. An individual mark may be
replaced by an upstream asset only after its source, retrieval date, license or brand guidance,
and file hash are recorded here.
