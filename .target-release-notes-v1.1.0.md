Ghostlight 1.1.0

ZCode joins the supported harness roster. Ghostlight's installer, doctor, and workbench now
detect, register, verify, and manage ZCode's MCP configuration in
`~/.zcode/cli/config.json`, and a hand-written entry pointing at the wrong executable is
reported as foreign evidence with its actual command instead of an undiagnosable failure.

The Chrome Web Store adapter stays at 1.0.0 and needs no update: adapter 1.0.0 covers
Ghostlight 1.1.0, recorded in the repository's compatibility map. Users of other MCP clients
update through their usual channel, for example:

    npx -y ghostlight@1.1.0

Verify: `SHA256SUMS` binds every asset to this release, and the six raw binaries carry GitHub
build provenance from workflow run 33097568009 at source revision `655e2078`
(`gh attestation verify <file>`).
