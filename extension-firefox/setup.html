Set up Ghostlight on this computer

Ghostlight is not installed on this computer yet. The extension came with your Chrome profile. Install Ghostlight here to connect it.

The extension is one half of Ghostlight. The other half is a local program that runs on this computer and talks to the extension directly. Chrome cannot install it for you, which is why this step is yours.

Install it

In a terminal:

npx -y ghostlight install

On Debian or Ubuntu you can install the package instead:

sudo apt install ./ghostlight_<version>_amd64.deb

Either route registers this browser and any MCP clients it finds. Nothing runs in the background until an agent or your browser asks for it.

Then check it

Run ghostlight doctor. It reports the whole chain: this extension, the native messaging registration, the connector, and the local service. When it is green, this extension's connection turns green on its own.

If your browser came from Snap or Flatpak

A sandboxed browser package cannot start a program on your computer, so native messaging will not work no matter what you install. Use a native Chrome, Edge, Brave, or Chromium package instead.

This page is bundled with the extension and needs no network. The full walkthrough, with screenshots and platform detail, is at sylin.org/ghostlight.
